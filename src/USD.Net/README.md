# USD.Net

A modern .NET library for creating and manipulating Universal Scene Description (USD) files.

## Overview

USD.Net provides a comprehensive C# API for working with Pixar's Universal Scene Description format, enabling you to:

- Create 3D scenes with geometry, transforms, and materials
- Export scenes to USDA files compatible with major 3D applications
- Build animated sequences with time-varying properties
- Construct complex scene hierarchies with USD's composition features

## Installation

```bash
dotnet add package USD.Net
```

## Quick Start

### Creating a Simple Scene

```csharp
using Pxr.Usd;
using Pxr.Usd.Sdf;
using Pxr.Usd.UsdGeom;

// Create a new stage
var stage = UsdStage.CreateInMemory();

// Define a transform hierarchy
var worldPath = new SdfPath("/World");
var world = UsdGeomXform.Define(stage, worldPath);

// Add a sphere
var spherePath = worldPath.AppendChild(new TfToken("Sphere"));
var sphere = UsdGeomSphere.Define(stage, spherePath, radius: 1.0);
sphere.SetDisplayColor(UsdGeomGprim.Red);

// Position the sphere
var translateOp = sphere.AddTranslateOp();
translateOp.Set(new GfVec3f(0, 2, 0));

// Export to file
stage.Export("my_scene.usda");
```

### Creating Animated Content

```csharp
// Create an animated cube
var cubePath = new SdfPath("/AnimatedCube");
var cube = UsdGeomCube.Define(stage, cubePath, size: 2.0);

// Animate rotation
var rotateOp = cube.AddRotateXYZOp();
for (int frame = 0; frame <= 60; frame++)
{
    var time = (double)frame;
    var rotation = new GfVec3f(0, frame * 6, 0); // Y-axis rotation
    rotateOp.Set(rotation, time);
}

// Set animation time range
stage.SetStartTimeCode(0);
stage.SetEndTimeCode(60);
stage.SetFramesPerSecond(24);
```

### Working with Meshes

```csharp
// Create a triangle mesh
var meshPath = new SdfPath("/TriangleMesh");
var mesh = UsdGeomMesh.Define(stage, meshPath);

// Define vertices
mesh.Points = new List<GfVec3f>
{
    new GfVec3f(-1, 0, 0),
    new GfVec3f( 1, 0, 0),
    new GfVec3f( 0, 2, 0)
};

// Define triangle
mesh.FaceVertexIndices = new List<int> { 0, 1, 2 };
mesh.FaceVertexCounts = new List<int> { 3 };

// Add normals
mesh.Normals = new List<GfVec3f>
{
    new GfVec3f(0, 0, 1),
    new GfVec3f(0, 0, 1),
    new GfVec3f(0, 0, 1)
};
mesh.SetNormalsInterpolation(UsdGeomInterpolation.Vertex);
```

## Core Concepts

### Stage
The container for all scene data. Create with `UsdStage.CreateInMemory()` or `UsdStage.CreateNew()`.

### Prims
The nodes in your scene graph. Define using schema classes like `UsdGeomXform.Define()`.

### Attributes
Properties on prims that can vary over time. Set values with optional time codes for animation.

### Paths
USD uses paths to identify objects. Create with `new SdfPath("/path/to/prim")`.

## Supported Geometry Types

- **UsdGeomXform** - Transform containers
- **UsdGeomMesh** - Polygon meshes with full topology support
- **UsdGeomSphere** - Sphere primitives
- **UsdGeomCube** - Cube/box primitives
- **UsdGeomBoundable** - Base for all boundable geometry

## Transform Operations

USD.Net supports the full USD transform operation stack:

```csharp
var xform = UsdGeomXformable.Define(stage, path);

// Add operations (order matters!)
var translate = xform.AddTranslateOp();
var rotateXYZ = xform.AddRotateXYZOp();
var scale = xform.AddScaleOp();

// Set values
translate.Set(new GfVec3f(10, 0, 0));
rotateXYZ.Set(new GfVec3f(0, 45, 0));
scale.Set(new GfVec3f(2, 2, 2));
```

## Display Properties

```csharp
// Set display color
gprim.SetDisplayColor(new GfVec3Color(0.8f, 0.2f, 0.2f));

// Set opacity
gprim.SetDisplayOpacity(0.5f);

// Set double-sided rendering
gprim.DoubleSided = true;
```

## Time-based Animation

```csharp
// Set values at specific times
attribute.Set(value1, time: 0.0);
attribute.Set(value2, time: 1.0);
attribute.Set(value3, time: 2.0);

// Query time samples
var times = attribute.GetTimeSamples();
var valueAtTime = attribute.Get(time: 1.5); // Interpolated
```

## File Export

```csharp
// Export to USDA (ASCII format)
stage.Export("output.usda");

// Export with custom comment
stage.Export("output.usda", addSourceFileComment: true);

// Export layer only
layer.Export("layer.usda", comment: "Generated by USD.Net");
```

## API Reference

### Namespaces

- `Pxr.Usd` - Core USD classes (UsdStage, UsdPrim, etc.)
- `Pxr.Usd.Sdf` - Scene description foundation (SdfPath, SdfLayer)
- `Pxr.Usd.UsdGeom` - Geometry schemas and types
- `Pxr.Base.Tf` - Foundation types (TfToken)
- `Pxr.Base.Vt` - Value types (VtValue)

### Key Classes

- **UsdStage** - Root container for scene data
- **UsdPrim** - Basic scene graph node
- **UsdAttribute** - Time-varying property
- **UsdRelationship** - Connection between prims
- **SdfPath** - Path to identify objects
- **TfToken** - Interned string for efficiency

## Compatibility

- **USD Specification**: Compatible with OpenUSD 24.x
- **.NET Requirements**: .NET 9.0 or later
- **Output Format**: USDA (USD ASCII) files readable by:
  - Blender (with USD addon)
  - Autodesk Maya (with USD plugin)
  - SideFX Houdini
  - NVIDIA Omniverse
  - Apple Reality Composer
  - And other USD-compatible tools

## Performance Tips

1. Use `CreateInMemory()` for temporary stages
2. Reuse `TfToken` instances for repeated string values
3. Batch time sample settings when creating animations
4. Use typed schema classes instead of generic prims
